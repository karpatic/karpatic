Lightweight Site Principles

  • Light mode / dark mode toggle.
  • No cookies.
  • No referrers.
  • Saturation color palette.
  • 90-50 character line length; ideally about 80 characters long.
  • px overrides user zoom; use em.
  • Use roughly 44px tap targets.
  • Use sans-serif and monospace.
  • People do not like animations.
  • Avoid requests after page load.
  • Avoid third-party resources.
  • Minimum line height: 1.5.
  • Content ratio: content divided by everything else, excluding favicons and webmanifest icons.
  • A TCP handshake takes 2 round trips, so 30 KB is okay.
  • Purely cosmetic animations can harm readers with learning and cognitive disabilities, including attention disorders.
  • Expand all "show content" sections for searching.
  • Underline links again.

Markdown Notes

Nested code fences in Markdown:

  • https://susam.net/nested-code-fences.html
  • Good CommonMark/GFM reminder.
  • Nested fenced blocks need a longer outer fence or tildes.
  • Inline code containing backticks needs multiple backticks as delimiters, often with spaces.
  • Useful whenever documenting Markdown examples that themselves contain code fences.
